Shell Data
==========

Shell datasets can be generated with the scripts in ``data_generators/``.

Detailed instructions for each generator script are available in ``data_generators/data_generator_README.md``.

Storage size
------------

- Full paper-scale shell set: about 17 GB.
- One realization with temperature and flux: about 1.7 GB.
- Single modality only: about 0.8 GB.

The lighter workflows are usually enough for diagnostics or training a single model.
