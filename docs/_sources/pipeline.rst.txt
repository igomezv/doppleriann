Pipeline
========

Overview
--------

``doppleriann`` supports an end-to-end workflow for radial-velocity modeling and shell-based inference:

- physics tools for CCF computation, shell-based Doppler injection, and signal analysis
- data handling for preprocessing and HDF5 dataset generation
- neural architectures including CNNs, VAEs, MLPs, and KANs
- analysis utilities for signal recovery, shell extraction, and uncertainty estimation

Canonical pipeline
------------------

The main paper workflow is:

``HARPS-N -> flux spectra -> temperature spectra -> planetary injections + CCF RV -> shell HDF5 -> HO/CV5 experiments``

Reference experiment folders:

- ``experiments/cnnShell_HO/``
- ``experiments/cnnShell_CV/``
